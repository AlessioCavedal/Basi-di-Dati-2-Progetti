Classe Progetto

[V.Progetto.fine_maggiore_inizio]

// La data di fine prevista di ogni proggetto deve essere maggiore della data di inizio

ALL p, a, fp, Progetto(p) AND avvio(p, a) AND fine_prevista(p, fp) → a < fp

[V.Progetto.avviato_solo_se_idoneo]

// Un progetto può essere avviato solo se il team copre tutte le specializzazioni richieste dagli scavi coinvolti

ALL p, t, spec, s Progetto(p) AND Team(t) AND prog_team(p, t) AND Specializzazione(spec) AND Scavo(s) AND scav_prog(s, p) AND scav_spec(s, spec) → EXISTS pers [ Persona(pers) AND afferisce(pers, t) AND pers_spec(pers, spec) ]

Classe Team

[V.Team.no_più_progetti_contemporanei]

// Un team non può essere associato a più progetti contemporaneamente

// Non devono esistere due date di fine fe1, fe2 tali cehe i due progetti si sovrappongono.

// Se a1 <= fe2 allora il primo inizia prima che il secondo finisca, se a2 <= fe1 allora il secondo inizia prima che il il primo finisca.

ALL t, p1, p2, a1, a2 Team(t) AND Progetto(p1) AND Progetto(p2) AND prog_team(p1, t) AND prog_team(p2, t) AND avvio(p1, a1) AND avvio(p2, a2) AND p1 != p2 → NOT EXISTS fe1, fe2 [ fine_effettiva(p1, fe1) AND fine_effettiva(p2, fe2) AND a1 <= fe2 AND a2 <= fe1 ]

Classe Scavo

[V.Scavo.coinvolto_in_un_progetto_solo_se_aperto]

// Un progetto può coinvolgere un o scavo solo se questo è aperto

ALL s, p, da, ap Scavo(s) AND Progetto(p) AND scav_prog(s, p) AND avvio(p, da) AND apertura(s, ap) → ap <= da AND ( NOT EXISTS dc [ chiusura(s, dc) ] OR EXISTS dc [ chiusura(s, dc) AND dc >= da ]

Classe Reperto

[V.Reperto.profondità_ritrovamento]

// La profondità di ritrovamento di un reperto non può superare la profondità massima dello scavo associato in cui è stato rinvenuto

ALL r, s, pr, pm Reperto(r) AND Scavo(s) AND rep_sca(r, s) AND profondità_ritrovamento(r, pr) AND prof_max(s, pm) → pm >= pr

[V.Reperto.data_ritrovamento_chiusura]

// La data di ritrovamento di un reperto deve essere precedente alla chiusura dello scavo

ALL r, s, dr Reperto(r) AND Scavo(s) AND rep_sca(r, s) AND data_ritrovamento(r, dr) AND EXISTS dc [ chiusura(s, dc) ] → dr <= dc

[V.Reperto.data_ritrovamento_apertura]

// La data di ritrovamento di un reperto deve essere successiva all’apertura dello scavo

ALL r, s, dr, a Reperto(r) AND Scavo(s) AND rep_sca(r, s) AND data_ritrovamento(r, dr) AND apertura(s, a) → dr >= a

Use-Case Calcolo Progetti a Rischio

pre:

        nessuna

post:

result = { p | Progetto(p) AND EXISTS sc [ prog_ente(p, e) AND Scavo(sc) AND scav_prog(sc, p) AND scav_spec(sc, s) ]  AND EXISTS t [ Team(t) AND prog_team(p, t) AND NOT EXISTS pers [ Persona(pers) AND afferisce(pers, t) AND pers_spec(pers, s) ] ] }

Use-Case Calcolo Siti

calcolo_siti(inzio : Data, fine : Data, k : Int > 0) : Sito[0..*]

pre:

        inizio <= fine

post:

result = { si | Sito(si) AND NOT EXISTS sc [ Scavo(sc) AND sit_scav(si, sc) AND # { r | Reperto(r) AND rep_sca(r, sc) AND EXISTS dr [ data_ritrovamento(r, dr) AND dr >= inizio AND dr <= fine ] } >= k }

Specifica realizzativa delle operazioni di Use-Case

progetti_a_rischio(s : Stringa, e : Stringa) : List<progetto>

pre:

        nessuna

post:

result = { p | Progetto(p) AND EXISTS sc [ prog_ente(p, e) AND Scavo(sc) AND scav_prog(sc, p) AND scav_spec(sc, s) ]  AND EXISTS t [ Team(t) AND prog_team(p, t) AND NOT EXISTS pers [ Persona(pers) AND afferisce(pers, t) AND pers_spec(pers, s) ] ] }

Sia R il risultato della seguente query SQL:

select p.cod, p.avvio

from Progetto p

where exists(select *

from Scavo sc, scav_spec ss, scav_prog spr

where p.ente = :e AND

        ss.specializzazione = :s AND

        ss.scavo = sc.cod AND

        spr.scavo = sc.cod AND

        spr.progetto = p.cod

)

        AND exists(select * 

from Team t

where p.team = t.cod AND

        not exists (select * 

                        from Persona pers, afferisce aff,pers_spec ps

                        where aff.persona = pers.cf AND 

                                aff.team = t.cod AND

                                ps.persona = pers.cf AND

                                ps.specializzazione = :s

)

)

result = R

calcolo_siti(inzio : Date, fine : Date, k : Int > 0) : List<Sito>

pre:

        inizio <= fine

post:

result = { si | Sito(si) AND NOT EXISTS sc [ Scavo(sc) AND sit_scav(si, sc) AND # { r | Reperto(r) AND rep_sca(r, sc) AND EXISTS dr [ data_ritrovamento(r, dr) AND dr >= inizio AND dr <= fine ] } >= k }

Sia R il risultato della seguente query SQL:

select si.cod

from Sito si

where not exists(select *

from Scavo sc

where sc.sito = si.cod 

AND ( select count(*)

        from Reperto r

        where r.scavo = sc.cod AND

                r.data_ritrovamento >= :inizio AND

                r.data_ritrovamento <= :fine

) >= :k

)

result = R
