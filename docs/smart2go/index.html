Use-Case Pre-registrazione

pre_registrazione_privato(n : Stringa, c : Stringa, cf : CF, dn : Data, pat : Patente, ind : Indirizzo, cc : CartaCredito) : Persona

pre:

        NOT EXISTS p Persona(p) AND cf(p, cf)

        NOT EXISTS p Persona(p) AND pat_pers(pat, p)

post:

        Il dominio di interpretazione viene esteso con l’elemento ALPHA

        Le relazioni che interpretano i simboli di predicato si modificano come segue:

        Persona(ALPHA)

        nome(ALPHA, n)

        cognome(ALPHA, c)

        cf(ALPHA, cf)

        data_nascita(ALPHA, dn)

        pat_pers(pat, ALPHA)

        Privato(ALPHA)

        InAttesaCentro(ALPHA)

        priv_cart(ALPHA, cc)

        indirizzo(ALPHA, ind)

        result = ALPHA

pre_registrazione_dipendente(n : Stringa, c : Stringa, cf : CF, dn : Data, pat : Patente, soc : Società) : Persona

pre:

        NOT EXISTS p Persona(p) AND cf(p, cf)

        NOT EXISTS p Persona(p) AND pat_pers(pat, p)

post:

        Il dominio di interpretazione viene esteso con l’elemento ALPHA

        Le relazioni che interpretano i simboli di predicato si modificano come segue:

        Persona(ALPHA)

        nome(ALPHA, n)

        cognome(ALPHA, c)

        cf(ALPHA, cf)

        data_nascita(ALPHA, dn)

        pat_pers(pat, ALPHA)

        Dipendente(ALPHA)

        dip_soc(ALPHA, soc)

        InAttesaResponsabile(ALPHA)

        

        result = ALPHA

Use-Case Approva / Rifiuta Pre-Registrazione

approva_rifiuta_dipendente(p : Persona, esito : {Approvato, Rifiutato}) : Persona

pre:

        InAttesaResponsabile(p) AND Dipendente(p)

        

        Sia r:Dipendente l’oggetto associato all’istanza di attore che ha invocato l’operazione

        EXISTS s [ Società(s) AND dip_soc(r, s) AND responsabile(r, s) AND dip_soc(p, s) ]

post:

        Se esito = Approvato allora:

        

        NOT InAttesaResponsabile(p)

        InAttesaCentro(p)

        

        Se esito = Rifiutato allora:

        NOT InAttesaResponsabile(p)

        Rifiutato(p)

        result = p

approva_rifiuta_registrazione(p: Persona, esito : {Approvato, Rifiutato}, cod: Stringa) : Persona

pre:

        InAttesaCentro(p)

        Se esito = Approvato allora cod deve essere valorizzato

        NOT EXISTS sc SmartCard(sc) AND codice(sc, cod)

post:

        Se esito = Rifiutato allora:

        NOT InAttesaCentro(p)

        Rifiutato(p)

        result = p

        Se esito = Approvato allora:

        

        Il dominio di interpretazione viene esteso con l’elemento ALPHA

        Socio(p)

        SmartCard(ALPHA)

        codice(ALPHA, cod)

        soc_card(p, ALPHA)

        result = ALPHA
