[V.Prenotazione.no_posti_maggiori_capienza_sistemazione]

[V.Prenotazione.no_due_contemporanee_stessa_abitazione]

// Non possono esserci due prenotazioni accettate contemporanee attive per la stessa sitemazione

Use-Case Ricerca abitazioni disponibili

ricerca_abitazioni(c: Città, i : Data, f : Data, posti : Int > 0) : Utente[0..*]

// I viaggiatori che desiderano organizzare un viaggio usufruendo del servizio devono poter interrogare il sistema per ottenere l’insieme di tutti gli iscritti della città desiderata che sono disposti a ricevere ospiti nel periodo richiesto e hanno, per le date richieste, posti sufficienti disponibili.

pre:

        i < f

post:

result = { u  | Utente(u) AND EXISTS a [ ut_abit(u, a) AND città_abit(c, a)

        // l’utente inserito nell’insieme deve essere il proprietario della casa e la casa deve trovarsi nella

città richiesta

        

AND NOT EXISTS t, ind, i1, f1 [ DataOra(t) AND abit_ind(a, ind) inizio(ind, i1) AND fine(ind, f1) AND t >= i1 AND t <= f1 AND t >= i AND t <= f ]  

// No indisponibilità nel periodo richiesto

AND NOT EXISTS p, sis, sta, t1, i2, f2 [ PrenAccettata(p) AND pren_sist(p, sis) AND sta_sis(sta,sis) AND abit_sta(a, sta) AND DataOra(t1) inizio(p, i2) AND fine(p, f2) AND t1 >= i2 AND t1 <= f2 AND t1 >= i AND t1 <= f ]

// No prenotazioni accettate nel periodo richiesto

AND posti <= somma dei valori di { cap | EXISTS sta,sis [ abit_sta(a, sta) AND sta_sis(sta, sis)

AND capienza(sis, cap) ] }

// Capienza sufficiente, il numero di posti deve essere minore della somma della capienze di tutte le sistemazioni dell’abitazione
