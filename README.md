# Progetti di Basi di Dati 2

Soluzioni proposte ai progetti del corso di **Basi di Dati, Modulo 2** — Superato con 30 e Lode - Sapienza Università di Roma, Laurea in Informatica, Prof. Toni Mancini.

📖 **[Leggi le soluzioni →](https://alessiocavedal.github.io/basi-di-dati-2-progetti/)**

> [!NOTE]
> Ho svolto i progetti in Google Docs, usando il formato senza pagine. Esportarli in PDF avrebbe rovinato l'impaginazione. I file di questo repository sono pagine HTML: per vedere le soluzioni usa il link qui sopra. 

## Cosa contiene

**Analisi concettuale**

- **Analisi dei requisiti** — riformulazione e disambiguazione del testo della traccia
- **Diagramma UML delle classi**
- **Specifica dei tipi di dato**
- **Specifica delle classi** — vincoli esterni espressi in logica del primo ordine (FOL) e operazioni di classe
- **Diagramma e specifica degli use case**

**Fase di progettazione**

- **Diagramma UML delle classi ristrutturato**
- **Definizione dei tipi di dato in SQL**
- **Vincoli esterni** emersi dalla ristrutturazione
- **Schema relazionale**
- **Trigger** per i vincoli esterni
- **Specifiche realizzative delle operazioni di use case**

## Avvertenza

Sono soluzioni **personali, non ufficiali e non validate dal docente**. Possono contenere errori o scelte di modellazione discutibili. Servono come termine di confronto dopo aver provato a svolgere il progetto per conto proprio, non come soluzione di riferimento — copiarle non ti insegna a progettare una base di dati, ed è esattamente quello che l'esame verifica.
